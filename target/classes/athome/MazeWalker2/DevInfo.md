# Modder / Dev Info
### When making new maps use the following naming conventions:
 - Name: level name
 - Time: turns left (AS AN INTEGER)
 - x: starting position x from top left (AS AN INTEGER with 0 based indexing)
 - y: starting position y from top left (AS AN INTEGER with 0 based indexing)

### When defining an entire campaign:
 - Include a config file with the following:
    - CONFIG
    - Name: campaign name
 - Don't reuse level names that already exist.
 - Make sure campaign folder is in Maps directory.
